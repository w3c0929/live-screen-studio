滚轮直接缩放，不再需要按住中键。

## 改进

- 放大状态下直接滚动滚轮即可调整倍数，不用再按住中键。
- 滚轮按固定档位跳变：1.25 / 1.5 / 1.75 / 2 / 2.5 / 3 / 4×，容易停在标准倍数。
- 高分辨率滚轮或触控板的小幅滚动会累积到一整格再切换，不会一下跳太多。
- 未放大时滚轮保持原样，继续滚动下层应用。
- 设置里的“使用鼠标中键放大/缩回”现在只控制中键单击，不再影响滚轮。

## 修复

- 「默认倍数」下拉里的 1.25× 和 1.75× 之前被格式化成 1.2× 和 1.8×，现在显示准确数值。

系统要求：Windows 10 2004+ 或 Windows 11，x64。
