# LiveZoom for Windows 0.8.0

聚光灯改为光标周围的干净圆形效果，并加入“始终使用自定义光标”。

## 新增 / 调整

- **聚光灯围绕光标**：`Ctrl+Shift+4` 不再依赖 OCR，而是在光标周围打开一圈聚光，
  再按一次取消。边缘干净、无光晕，跟随自定义光标移动。
- **始终使用自定义光标**：设置里新增开关，开启后非放大状态也隐藏系统光标并绘制
  自定义光标；关闭或退出时恢复系统光标。
- **设置窗口**：功能与说明分离，说明统一放在底部分隔区。

## 稳定性

本版同时做了一轮并发审计并修复：

- Magnification 引擎 shutdown 幂等，避免退出时二次释放 DLL 后的函数指针调用。
- 输入钩子线程启动/停止使用条件变量同步，`threadId` 改为原子变量，避免启动超时竞态。
- OCR 服务在工作线程停止后不再接受新请求。
- 放大缩回的光标恢复重试与“始终自定义光标”互斥，避免缩回后出现双光标。
- 放大窗口创建时不再无条件恢复系统光标。

## 安装

- 便携版：`LiveZoom-0.8.0-windows-x64-portable.zip`
- 安装包：`LiveZoom-0.8.0-windows-x64-setup.exe`

系统要求：Windows 10 2004+ 或 Windows 11，x64。

下载后请核对 `SHA256SUMS.txt`。
