# LiveZoom for Windows 0.2.2

修复放大后笔迹与点击位置不准确的问题，尤其是 125% / 150% 等高 DPI 缩放环境。

## 修复

- **笔迹跟随放大后的光标**：笔迹点现在使用显示器本地的物理坐标，并与放大镜使用
  同一套视口变换。镜头跟随到安全区后，笔迹和可见光标仍然重合。
- **点击波纹显示在放大光标处**：波纹位置按当前视口映射，不再落在隐藏的真实指针位置。
- **点击转发修复高 DPI 偏移**：`SendInput` 的绝对坐标改用显示器物理矩形做归一化，
  不再使用会被 DPI 虚拟化的 `GetSystemMetrics`，因此点击落在用户看到的放大内容上。
- 笔迹采样使用 `GetCursorPos` 的物理坐标，不依赖低层钩子可能被 DPI 虚拟化的坐标。

## 功能

- 中键平滑放大/缩回，1.25×–4×，滚轮调倍，边缘跟随
- 放大后左键画线，Shift 直线，Ctrl + 左键正常拖拽
- 单击转发给下层应用并显示波纹；右键撤销；Esc 清除
- GUI 启动，无控制台；日志写入 `%APPDATA%\LiveZoom\livezoom.log`
- 托盘菜单与设置窗口，OBS 显示器采集可直接拍到

## 安装

- 便携版：`LiveZoom-0.2.2-windows-x64-portable.zip`
- 安装包：`LiveZoom-0.2.2-windows-x64-setup.exe`

系统要求：Windows 10 2004+ 或 Windows 11，x64。

下载后请核对 `SHA256SUMS.txt`。
