# LiveZoom for Windows 0.8.1

修复“始终使用自定义光标”后鼠标失去原有形态和提示的问题。

## 修复

- 非放大状态只替换系统普通箭头（OCR_NORMAL），不再替换全部系统光标。
- 文本 I 字形、链接手形、调整大小、移动等系统光标保持原生图像和含义；
  第三方应用自定义的光标也保持原样。
- 只在当前光标确实是透明替换箭头时才绘制自定义光标；离开普通箭头区域时
  自动隐藏自绘光标，让系统光标接管。
- 覆盖层会把 WM_SETCURSOR 转发给下方真实窗口，避免顶层透明窗口抢走光标。
- 设置里新增“开机启动 LiveZoom”开关，直接写入/删除当前用户的 Run 注册表项。

0.8.0 的光标周围圆形聚光灯（无光晕）、自定义跟随边缘、OCR 快捷键录制、
并发修复和设置窗口底部分区说明均保留。

## 安装

- 便携版：`LiveZoom-0.8.1-windows-x64-portable.zip`
- 安装包：`LiveZoom-0.8.1-windows-x64-setup.exe`

系统要求：Windows 10 2004+ 或 Windows 11，x64。

下载后请核对 `SHA256SUMS.txt`。
