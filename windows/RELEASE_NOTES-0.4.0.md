# LiveZoom for Windows 0.4.0

放大状态下的光标改为覆盖层自绘，并支持调整大小。

## 新增

- **自定义光标**：放大时隐藏系统光标，在标注层上绘制经典箭头（深色填充、白色描边），
  位置与放大后的光标、笔迹、点击波纹完全对齐。
- **光标大小**：0.8× / 1.0× / 1.2× / 1.5× / 2.0×，随放大倍数一起缩放。
- **硬件光标恢复**：进入放大时用透明光标隐藏系统指针，缩回时重载光标方案并重试；
  另外增加看门狗，主线程卡住超过 2 秒会自动恢复指针。

## 说明

- 本版只有经典箭头一种自定义样式；海蓝、日落、薄荷、圆点、聚光等样式、
  光标平滑/静止隐藏、常驻自定义光标将在后续版本加入。
- 0.3.0 的笔迹样式/颜色/粗细、点击效果/颜色、靠边跟随和高 DPI 对齐保持不变。

## 安装

- 便携版：`LiveZoom-0.4.0-windows-x64-portable.zip`
- 安装包：`LiveZoom-0.4.0-windows-x64-setup.exe`

系统要求：Windows 10 2004+ 或 Windows 11，x64。

下载后请核对 `SHA256SUMS.txt`。
