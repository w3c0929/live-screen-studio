# LiveZoom for Windows 0.5.0

补齐光标样式和光标体验。

## 新增

- 7 种光标样式：经典黑、经典白、海蓝、日落、薄荷、圆点、聚光
- 光标大小：0.8× / 1.0× / 1.2× / 1.5× / 2.0×
- 光标平滑（默认关闭）
- 静止 3 秒后自动隐藏，移动后淡入
- 设置窗口增加光标样式、光标平滑、静止隐藏选项

自定义光标继续使用透明系统光标 + 覆盖层绘制，缩回时恢复系统光标；
看门狗和缩回重试保留。

## 说明

- 非放大状态下的常驻自定义光标、系统原生光标样式尚未实现。
- 0.4.0 的光标大小、透明光标恢复与笔迹/点击对齐保持不变。

## 安装

- 便携版：`LiveZoom-0.5.0-windows-x64-portable.zip`
- 安装包：`LiveZoom-0.5.0-windows-x64-setup.exe`

系统要求：Windows 10 2004+ 或 Windows 11，x64。

下载后请核对 `SHA256SUMS.txt`。
