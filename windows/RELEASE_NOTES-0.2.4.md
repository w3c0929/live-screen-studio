# LiveZoom for Windows 0.2.4

调整跟随触发位置：画布现在会等放大后的光标接近屏幕边缘才开始移动。

## 检查结果

坐标链路本身是正确的：日志确认显示器为 2560×1440、光标/视口坐标一致，
跟随确实在预设的安全区边界触发。问题是 Windows 版沿用了 macOS 的 25% 安全区，
在 2× 放大时可见光标刚到屏幕 75% 处就开始移动，主观上离边缘还很远。

## 调整

- **平稳**：距边缘 8% 开始跟随，跟随后停在 14% 处
- **标准**：距边缘 6% 开始跟随，跟随后停在 11% 处
- **灵敏**：距边缘 4% 开始跟随，跟随后停在 8% 处

三种模式仍保留原来的跟随速度差异；现在触发点都明显更靠边。设置窗口里也补充了说明。

日志新增 `follow starts: ... xFraction=...`，便于继续核对触发位置。

0.2.2 的笔迹/点击高 DPI 对齐、0.2.3 的光标恢复修复保持不变。

## 安装

- 便携版：`LiveZoom-0.2.4-windows-x64-portable.zip`
- 安装包：`LiveZoom-0.2.4-windows-x64-setup.exe`

系统要求：Windows 10 2004+ 或 Windows 11，x64。

下载后请核对 `SHA256SUMS.txt`。
