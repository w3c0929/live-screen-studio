# LiveZoom for Windows 0.7.0

跟随边缘触发距离和 OCR 高亮快捷键都可以自定义了。

## 新增

- **自定义跟随边缘**：平稳 / 标准 / 灵敏三档可分别设置为距屏幕边缘 1%–20%；
  默认值仍为 6% / 4% / 2%。
- **自定义 OCR 高亮快捷键**：设置 → 高亮快捷键，点击“录制”后按下组合键即可；
  默认仍是 Ctrl+Shift+1..4（框住 / 划线 / 荧光笔 / 聚光灯）。快捷键随设置保存。
- **设置窗口重排**：功能选项按放大、标注与点击、跟随边缘三列排列；
  说明注释统一放在底部，通过分隔线与功能区分开。

## 保持

- OCR 高亮、7 种光标样式、光标平滑/静止隐藏、笔迹样式/颜色/粗细、点击效果、
  高 DPI 对齐与光标恢复都保持不变。

## 安装

- 便携版：`LiveZoom-0.7.0-windows-x64-portable.zip`
- 安装包：`LiveZoom-0.7.0-windows-x64-setup.exe`

系统要求：Windows 10 2004+ 或 Windows 11，x64。

下载后请核对 `SHA256SUMS.txt`。
