# LiveZoom for Windows 0.2.1

修复 0.2.0 的两个体验问题。

## 修复

- **画线不再只出现一个点**：左键按下即开始记录笔迹，每帧采样光标位置，
  不再依赖可能被吞掉的鼠标移动事件；松开时根据移动距离决定是画线还是点击。
- **不再弹出控制台窗口**：程序改为 GUI 子系统启动，诊断日志写入
  `%APPDATA%\LiveZoom\livezoom.log`，每次启动重新写入。

## 功能（与 0.2.0 相同）

- 中键平滑放大/缩回，1.25×–4×，滚轮调倍，边缘跟随
- 放大后左键画线，Shift 直线，Ctrl + 左键正常拖拽
- 单击转发给下层应用并显示波纹；右键撤销；Esc 清除
- 托盘菜单与设置窗口，OBS 显示器采集可直接拍到

## 安装

- 便携版：`LiveZoom-0.2.1-windows-x64-portable.zip`
- 安装包：`LiveZoom-0.2.1-windows-x64-setup.exe`

系统要求：Windows 10 2004+ 或 Windows 11，x64。

## 说明

画线时鼠标会跟随笔尖移动（不再冻结系统光标）；这是为了在 Windows 上稳定获取
连续的笔迹采样。放大状态下的光标仍被限制在当前显示器内。

下载后请核对 `SHA256SUMS.txt`。
