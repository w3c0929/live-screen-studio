# LiveZoom for Windows 0.2.5

进一步把跟随触发点贴近屏幕边缘：

- **平稳**：距边缘 6% 开始跟随
- **标准**：距边缘 4% 开始跟随
- **灵敏**：距边缘 2% 开始跟随

三种模式的跟随速度保持不变。0.2.2 的笔迹/点击高 DPI 对齐、0.2.3 的光标恢复、
0.2.4 的靠边跟随调整均保留。

## 安装

- 便携版：`LiveZoom-0.2.5-windows-x64-portable.zip`
- 安装包：`LiveZoom-0.2.5-windows-x64-setup.exe`

系统要求：Windows 10 2004+ 或 Windows 11，x64。

下载后请核对 `SHA256SUMS.txt`。
