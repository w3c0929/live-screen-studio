# LiveZoom for Windows 0.3.0

标注与点击效果现在可以在设置里选择。

## 新增

- 笔迹样式：马克笔、霓虹、荧光笔、箭头、流动虚线
- 笔迹颜色：红、黄、绿、蓝、粉、白
- 笔迹粗细：2 / 3 / 5 / 8 / 12 / 16 px
- 点击效果：无、波纹、光圈
- 点击颜色：蓝、黄、红、绿、白
- 设置窗口重新排版，放大和标注两组选项并列显示

## 保持

- 0.2.2 的笔迹/点击高 DPI 对齐
- 0.2.3 的缩回光标恢复
- 0.2.4 / 0.2.5 的靠边跟随（平稳 6%、标准 4%、灵敏 2%）
- GUI 启动无控制台，日志写入 `%APPDATA%\LiveZoom\livezoom.log`

## 安装

- 便携版：`LiveZoom-0.3.0-windows-x64-portable.zip`
- 安装包：`LiveZoom-0.3.0-windows-x64-setup.exe`

系统要求：Windows 10 2004+ 或 Windows 11，x64。

下载后请核对 `SHA256SUMS.txt`。
