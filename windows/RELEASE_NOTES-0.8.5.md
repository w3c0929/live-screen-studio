点击波纹和光圈动画更平滑，放大静止时不再占用额外性能。

## 修复

- 放大画面在镜头完全静止时不再每帧重复刷新 Magnification 放大引擎。此前即使画面
  没有变化也会反复重绘整屏，挤占了叠加层动画的帧时间，导致点击波纹显得卡顿。
- 提高帧定时器精度，点击波纹、光圈、光标平滑和镜头跟随的动画节奏更稳定，更接近
  显示器刷新率。
- 功能与设置项没有变化。
