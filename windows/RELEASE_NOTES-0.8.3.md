放大/缩回新增可自定义的全局快捷键，不再强制使用鼠标中键。

## 新增

- 放大/缩回快捷键，默认 `Ctrl+Shift+Z`，在设置 → 快捷键中点击“录制”即可改成任意
  Ctrl/Alt/Shift/Win 组合。
- 鼠标中键继续可用，两种方式互不影响。
- 快捷键在放大和缩回状态都能触发；录制快捷键时会临时抑制热键，避免录制过程中误触发放大。

## 安装

- 便携版：`LiveZoom-0.8.3-windows-x64-portable.zip`
- 安装包：`LiveZoom-0.8.3-windows-x64-setup.exe`

系统要求：Windows 10 2004+ 或 Windows 11，x64。

下载后请核对 `SHA256SUMS.txt`。
