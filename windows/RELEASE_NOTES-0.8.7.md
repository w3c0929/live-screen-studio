放大画面回到平滑显示，光标在录屏时更跟手。

## 调整

- 光标平滑增加了最大滞后限制：自绘光标与真实指针的距离任何时刻都不超过 2 个屏幕像素，
  快速移动或录屏时不会再明显拖在鼠标后面。
- 叠加层不再等待垂直同步后提交，减少一帧左右的显示延迟。
- “整数倍时按像素锐利显示”默认关闭。整数倍放大本质上是把已经渲染好的桌面逐像素放大：
  平滑会略软，锐利会呈块状，Windows 放大 API 只提供这两种采样方式，没有兼顾两者的
  第三档。默认使用平滑，需要硬朗像素时可在设置里勾选。
- 追求完全 1:1 指针的用户，可以在设置里取消“光标平滑”。
