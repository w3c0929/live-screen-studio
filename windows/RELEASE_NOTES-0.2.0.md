# LiveZoom for Windows 0.2.0

Windows 10/11 x64 的首个可用版本：把 macOS 版的核心体验带到 Windows，使用 C++20 + 原生 Win32 / Direct3D 11 / Direct2D / DirectComposition 实现。

## 功能

- 单击鼠标中键：以光标为中心平滑放大（默认 2×），再按一次缩回
- 按住中键滚动滚轮：调整放大倍数（1.25× 到 4×）
- 放大后移动鼠标：光标在画面中间时镜头不动，靠近边缘才平稳跟随
- 放大后左键拖动：画线；Shift 画直线；Ctrl + 左键拖动保留正常拖拽
- 放大后单击：点击转发给下层应用，同时显示波纹
- 右键撤销一笔；Esc 清除全部笔迹
- 系统托盘菜单：放大/缩回、启用、设置、退出
- 设置窗口：默认倍数、跟随速度、放大时画线、画面平滑、排除 OBS 窗口
- OBS 使用「显示器采集」即可拍到放大后的画面和笔迹，无需修改 OBS 设置

## 安装

- **便携版**：下载 `LiveZoom-0.2.0-windows-x64-portable.zip`，解压后运行 `livezoom_win.exe`
- **安装包**：下载 `LiveZoom-0.2.0-windows-x64-setup.exe`，按当前用户安装到
  `%LOCALAPPDATA%\Programs\LiveZoom`，无需管理员权限；可勾选桌面快捷方式和开机启动

系统要求：Windows 10 2004+ 或 Windows 11，x64。

## 已知限制

- 文字识别高亮（框住/划线/荧光笔/聚光灯）尚未接入 Windows 版
- 自定义光标样式、光标平滑/静止隐藏、应用内开机启动开关尚未实现
- 发布包未做代码签名，SmartScreen 可能提示
- 全局低级钩子和光标控制可能被部分安全软件拦截
- 独占全屏游戏、受 DRM 保护的内容、部分远程桌面场景可能无法放大
